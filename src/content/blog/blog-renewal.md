티스토리 같은 블로그 플랫폼에 필요한 기능 목록을 보고, **혼자 쓰는 정적 블로그**에 필요한 것만 골라서 붙였어요.

## 넣은 것

### 글쓰기

- 마크다운으로 쓰고, 코드 블록은 라이트/다크 모드에 맞춰 색이 바뀌어요. 마우스를 올리면 **복사** 버튼이 나와요.
- 소제목이 두 개 이상이면 글 위에 **목차**가 자동으로 생겨요.
- 글마다 **읽는 시간**과 **이전 글 / 다음 글** 링크가 붙어요.

### 발행 관리

- `draft: true` 면 초안이라 블로그에 안 올라가요.
- `pubDate`를 미래 시간으로 적으면 **예약 발행**이에요. GitHub Actions가 매시 정각에 다시 빌드하면서 시간이 된 글을 공개해요.
- 로컬(`npm run dev`)에서는 초안과 예약 글도 `초안`, `예약` 표시와 함께 미리 볼 수 있어요.

### 분류

카테고리를 `'개발/Astro'` 처럼 `/`로 나눠 적으면 **대/중/소 계층**이 돼요. 상위 카테고리를 누르면 하위 글까지 모두 보여요.

```md
---
category: '개발/Astro'
tags: ['astro', '블로그']
---
```

### 찾기와 소통

- 서버 없이 동작하는 **검색** 페이지를 만들었어요. 제목, 본문, 카테고리, 태그를 모두 찾아요.
- **댓글과 공감**은 [giscus](https://giscus.app)로 붙였어요. GitHub Discussions에 저장돼서 따로 서버가 필요 없어요.

### 검색엔진·공유

`sitemap.xml`, `rss.xml`에 더해 **Open Graph** 태그를 넣어서 카카오톡이나 SNS에 링크를 공유하면 제목과 요약이 미리보기로 떠요.

## 뺀 것

| 기능 | 뺀 이유 |
| --- | --- |
| 회원가입, 소셜 로그인, 팀블로그 | 혼자 쓰는 블로그라 필요 없음 |
| 비공개·보호글 | 정적 사이트는 파일이 그대로 공개돼서 진짜로 숨길 수 없음 (대신 초안 기능 사용) |
| 웹 에디터, 자동 저장 | VS Code로 마크다운을 쓰고 git이 기록을 남김 |
| 광고, 스킨 편집기 | 지금 단계에선 불필요 |
| 방문자 통계 | 나중에 필요하면 추가 |
| 백업 | GitHub 저장소 자체가 백업 |
